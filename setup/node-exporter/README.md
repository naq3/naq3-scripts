# node-exporter-installer

Automatically download [node_exporter](https://github.com/prometheus/node_exporter) latest tar.gz archive:

* Ubuntu 16.04+
* Debian 9
* Centos 6+
* RHEL 6+

## Usage

```bash
curl -sSL https://raw.githubusercontent.com/naq3/naq3-scripts/master/setup/node-exporter/install.sh | sudo sh
```
